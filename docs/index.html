현재 가장 중요한 질문

여러 서비스와 LLM이 저장장치를 함께 쓸 때, logical bytes 회계는 내부 NAND 작업과 마모를 충분히 표현하는가?

OS에서 1 GiB를 썼다고 보여도 SSD는 살아 있는 데이터를 옮기느라 내부에서 더 많이 쓸 수 있습니다. 그 차이가 실제로 크고 반복되는지 먼저 봅니다.

지금 어디까지 왔나

✅ 새 세션 KVM 검사 · pinned build · guest boot · namespace · 16 MiB sanity · native counter 수집

✅ 공용 서버 설정 변경 없음. 작은 VM 하나만 실행했고 현재 정상 종료했습니다.

✅ Phase 2 pilot 완료: GC가 발생하는 같은 초기 상태에서 sequential/random을 각 3회 비교했습니다. 차이와 한계 보기. 다음 실험은 승인 대기입니다.

집에서도 계속 작업할 수 있습니다

집 Windows/WSL에서는 코드와 설명을 편집하고 분석할 수 있습니다. FEMU 실행은 집의 물리 Ubuntu 또는 연구실 Linux에서 합니다. 같은 Git/config를 쓰고 장비 정보와 resource 상태를 함께 기록하면 됩니다.

⚠️ 현재 WSL은 upstream 지원 환경이 아닙니다. 연구실 장비가 유일한 선택은 아니지만, 물리 Linux가 없는 현재에는 원격 실행이 현실적인 후보입니다.
